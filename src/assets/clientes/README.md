# Logos de clientes

Deja aquí los logos de las empresas que pueden aparecer públicamente en la web.

- Formatos recomendados: SVG o PNG/WebP con fondo transparente.
- Nombra cada archivo con el nombre de la empresa, por ejemplo `empresa-ejemplo.svg`.
- Evita variantes repetidas y confirma que Divina Pausa tiene autorización para publicar cada marca.
- Las imágenes de esta carpeta aparecen automáticamente en el slider después del hero al volver a compilar.

Este archivo no se muestra en la web.
