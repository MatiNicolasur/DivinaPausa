# Fotografías de los fundadores

Deja aquí la fotografía elegida para la página Nosotros.

- Nombre recomendado: `fundadores-divina-pausa.jpg`.
- Ideal: horizontal, al menos 1800 px de ancho, con espacio alrededor de ambas personas para adaptar el encuadre a móvil.
- Si tienes varias opciones, usa `fundadores-divina-pausa-01.jpg`, `-02.jpg`, etc.; se seleccionará la mejor para el layout.

Después de cargarla, se reemplazará la imagen actual de Nosotros.
