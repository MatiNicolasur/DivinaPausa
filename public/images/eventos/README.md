# Fotografías de eventos

Deja aquí las fotografías reales que quieras considerar para la galería.

- Formatos recomendados: JPG o WebP.
- Ideal: lado mayor entre 1600 y 2400 px, sin capturas de pantalla ni archivos reenviados varias veces.
- Nombres sugeridos: `coffee-break-oficina-01.jpg`, `brunch-corporativo-01.jpg`.
- Si aparecen personas reconocibles, confirma que las imágenes pueden publicarse.

Después de cargarlas, se revisarán encuadres, peso, textos alternativos y orden antes de incorporarlas.
